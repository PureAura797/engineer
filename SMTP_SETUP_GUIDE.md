# Настройка отправки заявок на почту

Этот файл содержит инструкцию по настройке реальной отправки писем с сайта на адрес `gerasimov@mzta.ru`. 

Система загрузки файлов и отправки форм уже полностью запрограммирована (маршрут `/api/send-lead`). Однако, чтобы письма физически уходили, сайту нужен технический "ящик-отправитель" (SMTP-сервер).

## Что нужно сделать

В корне проекта (где лежит `package.json`) создайте файл с названием `.env.local` и вставьте в него следующие строки, заменив значения на ваши реальные доступы к почтовому ящику:

```env
# Данные вашего технического почтового ящика, с которого будут улетать письма
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=465
SMTP_USER=ваша-почта@yandex.ru
SMTP_PASS=ваш-пароль-от-почты-или-пароль-приложения
```

### Важные замечания:
- Если вы используете Яндекс.Почту или Mail.ru, в поле `SMTP_PASS` обычно нужно вставлять **не обычный пароль от аккаунта**, а специально сгенерированный "Пароль приложения" (создается в настройках безопасности почты).
- Как только вы добавите файл `.env.local`, перезапустите локальный сервер (`npm run dev`), и форма начнет реально присылать вам файлы и контакты на почту!
